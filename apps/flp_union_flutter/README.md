# flutter_empty_project

A new empty Flutter project starter.

## Getting Started

This project is a minimal Flutter application skeleton with `pubspec.yaml`,
`lib/main.dart`, and a basic widget test.

It does **not** include the platform-specific folders (`android/`, `ios/`,
`web/`, `windows/`, `macos/`, `linux/`) because those are auto-generated by
the Flutter SDK and are large/binary-heavy. To generate them, unzip this
project into an empty folder and run:

```bash
flutter create .
flutter pub get
flutter run
```

This regenerates the platform folders in place around the existing
`lib/`, `pubspec.yaml`, and `test/` files without overwriting your code.
